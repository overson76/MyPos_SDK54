## 🔴 이번에 밟은 함정 3종 (재발 방지)

### ① 윈도우 배치 파일은 CRLF 필수

LF 줄바꿈으로 저장한 `.cmd` 는 **창이 깜빡하고 즉시 종료**된다. 에러 메시지조차 안 남는다.
한글까지 UTF-8 로 들어있으면 콘솔 코드페이지와 어긋나 더 확실히 죽는다.

**처방**: 역할 분리
- `.cmd` = CRLF + **영문만** (cmd 가 확실히 읽음)
- `.ps1` = **UTF-8 BOM** (PowerShell 5.1 이 한글을 정확히 읽으려면 BOM 필요)

BOM 붙여 저장하는 법:
```powershell
[IO.File]::WriteAllText($path, $text, (New-Object Text.UTF8Encoding($true)))
```

### ② PowerShell 파이프가 비밀값 앞에 BOM 을 끼워넣는다

```powershell
$token | gh secret set CLOUDFLARE_API_TOKEN   # ← chcp 65001 환경에서 BOM 삽입됨
```

결과: wrangler 가
`The configured Cloudflare API token contains a character that cannot be used in an HTTP Authorization header: "\uFEFF"`
로 실패. **토큰은 멀쩡한데 배포만 실패**해서 원인 찾기가 고약하다.

실측 확인:

| 방식 | 파일 첫 3바이트 |
|---|---|
| `Out-File -Encoding utf8` / 파이프 | `239,187,191` ← BOM |
| `UTF8Encoding($false)` + stdin 리다이렉트 | `99,102,117` (= `cfu`) |

**처방**: BOM 없는 임시파일로 떨구고 `cmd /c "gh secret set ... < file"`, 쓰고 나면 덮어쓰고 삭제.

### ③ wrangler 로컬 OAuth ≠ CI 용 API 토큰

로컬 `deploy:web` 이 잘 도는 것과 CI 가 배포할 수 있는 것은 **별개**다.

| | 저장 위치 | 형태 | 만료 |
|---|---|---|---|
| 로컬 | `%APPDATA%\xdg.config\.wrangler\config\default.toml` | `oauth_token` + `refresh_token` | 있음(자동 갱신) |
| CI | GitHub Secret `CLOUDFLARE_API_TOKEN` | API 토큰 | 없음 |

**Cloudflare 는 생성 직후 한 번만 토큰 값을 보여준다.** 기존 토큰 목록이 있어도 값 재조회 불가 — 새로 만들거나 Roll 해야 한다.

### 부수: Read-Host 는 기본이 화면 표시

`Read-Host '토큰'` 은 입력을 **그대로 화면에 찍는다** → 스크린샷 한 장에 비밀값이 샌다.
비밀값 입력은 반드시 `-AsSecureString`.

## 핵심 기술 결정 — 왜 이렇게 했나

**1. 굵기를 두 방식으로 이중 적용한 이유**
프린터 모델에 따라 `ESC !` 의 bold 비트(0x08)만 인식하거나 `ESC E` 만 인식하는 경우가 있다. 둘 다 걸어야 어느 프린터에서든 확실히 진해진다. 리셋도 양쪽 다 한다.

**2. 정렬을 프린터에 맡긴 이유**
`centerText` 는 32칼럼 기준으로 공백을 채운다. 글씨가 가로 2배가 되면 실제 폭이 2배라 계산이 깨져 오른쪽으로 밀린다. `ESC a 1` 은 프린터가 실제 폭을 알고 맞추므로 크기와 무관하게 정확하다.

**3. 텍스트 빌더에 넣은 이유 (재확인)**
바이트 래퍼(`buildReceiptBytes`/`buildTextBytes`)와 `electron/printer/print.js` 는 **.exe 메인 프로세스 번들**이라 거기 넣으면 매장 반영에 .exe 재빌드 + 자동 업데이트 사이클이 필요하다. 텍스트 빌더는 라이브 URL 번들(렌더러)에서 돌아 `deploy:web` + 새로고침이면 끝. `freezeToRawText()` 가 결제 영수증도 렌더러에서 텍스트로 굳혀 넘기므로 **모든 출력 경로가 이 빠른 길을 탄다.**

**4. 토큰 생성을 사용자에게 남긴 이유**
계정 자격증명을 새로 발급해 다른 서비스에 심는 일은 사용자 손을 거치는 게 맞다. 대신 앞뒤(로그인 확인 / `DOTENV` 등록 / 페이지 열기 / 등록·검증·배포 자동화 스크립트 / 결과 확인)를 전부 처리해 **붙여넣기 1회**로 줄였다.
